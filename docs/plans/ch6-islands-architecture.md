## 4. 技術方案

- **路由**：靜態 `ch6/islands.html` → Vercel `cleanUrls` 為 `/ch6/islands`。
- **3D**：Three.js（ESM，`importmap` + jsDelivr），`InstancedMesh` 鋪六角地形、每島一組 low-poly 主題 mesh。
- **控制**：`OrbitControls`（角度／距離 clamp）；觸控與 `touch-action: none` 防捲動衝突。
- **模組**：
  - `js/ch6-islands/config.js` — 島嶼座標、文案摘要、講義 URL、任務 meta（**不重複長篇課文**）。
  - `js/ch6-islands/progress.js` — `localStorage` `jpwn.ch6islands.v1`。
  - `js/ch6-islands/scene-world.js` — 場景、選取、鏡頭。
  - `js/ch6-islands/ui-panel.js` — 面板、任務 overlay。
  - `js/ch6-islands/labs/atom-lab.js` — 原子模型互動（變因：p/n/e → Z、A、電荷、元素名）。
  - `js/ch6-islands/fallback-2d.js` — WebGL 失敗時 2D 島嶼清單。
- **與講義整合**：章首入口；各節可加深連結 `ch6/islands?island=atom`；互動內「閱讀講義」連到 `sections/6-*.html`。
- **不採用**：全站 React 重構；題庫內容複製貼上。

## 5. 資料重用策略

- 科學敘述以講義為準：面板只放**學習目標、探究問句、摘要**（摘自 `config-ch6.js` 的 `ask`／`summary`）。
- 元素名稱、符號、Z 1–20 等用小型 `config` 表，與 6-2／6-3 一致。
- 段考題、挖空、KaTeX 仍只在講義／exam 維護。

## 7. 科學與模型警語（全島共通）

- 電子環為**示意**，非真實軌道或機率雲。
- 分子拖拽組裝**僅適用共價分子**（如 H₂O、O₂），離子化合物（NaCl）用離子排列示意。
- 分解島：氧化汞、通電分解為**模擬**；不 encourage 自行實作危險實驗。

## 8. 測試計畫

- `@basic`：`/ch6/islands` 標題、2D 後備或 canvas 存在；`ch6.html` 群島入口連結。
- 擴充：`?island=atom` 開啟任務 UI；localStorage 寫入 completed。
- WebGL：依賴 CI Chromium；失敗路徑以 mock 或強制 fallback 選測。

## 9. 已知限制（MVP）

- 僅 `atom` 具完整互動；其餘島可選取、看目標、連講義（Phase 4 補任務）。
- Three.js 走 CDN，離線 PWA 未預快取群島 bundle（可後續加入 `sw-main` 選快取）。
- 未接題庫／Gist 同步。
