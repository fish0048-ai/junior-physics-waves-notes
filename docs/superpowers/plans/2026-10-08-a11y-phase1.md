# 第一階段無障礙修正 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不改教材、不改 React、不在本機跑 Node 的前提下，修正焦點、點擊區、減少動態、動畫框高度、對錯提示與錨點被遮住。

**Architecture:** 只改共用 `css/style.css`、`js/app.js`，以及唯一會自動播放的 `animations/pinhole-image.html`。雲端用 GitHub Actions 跑 Playwright，本機不執行 npm。

**Tech Stack:** 原生 HTML/CSS/JavaScript、Playwright 1.64.0（僅 GitHub runner）。

## 衝突檢查（可一起做）

1. `:focus-visible` 只補外框；挖空原本的 `outline: none` 會拿掉，避免蓋掉新外框。
2. 筆記模式的 30/28px 覆寫刪掉，改為至少 44px；頂欄已有 `flex-wrap`，變高時換行，不縮小按鈕。錨點留白用較大的手機值，對應換行後的頂欄。
3. `prefers-reduced-motion` 只停自動動畫與 hover 位移；播放鈕保留。針孔成像改為預設暫停，點一下仍可播放。
4. iframe 仍只接受自己頁面、自己框架送來的高度。沒收到時才改成可捲動的備援，避免和成功量高互相覆寫。
5. toast 的 `aria-live` 與「正確／再看」文字用 CSS 偽元素，不改題幹與答案。
6. `scroll-margin` 不改版面高度；列印時歸零。

## Tasks

- 焦點外框：按鈕、導覽、挖空、選項。
- 筆記模式點擊區：`body.ink-draw` 至少 44×44px。
- 減少動態：CSS 與針孔成像初始暫停。
- iframe：可信高度通訊；逾時改 `.is-anim-fallback`。
- 提示：`#toast` 設 `aria-live="polite"`；對錯加文字。
- 錨點：`scroll-padding-top` 與 `scroll-margin-top`。
- 雲端測試：`tests/a11y-phase1.spec.ts` 與 workflow。本機不跑。
