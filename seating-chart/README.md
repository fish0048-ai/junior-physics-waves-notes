# 課堂座位表（Google 試算表 + Apps Script）

用同一份 Google 試算表當資料庫。電腦、平板開同一個網址，拖座位、加減分、抽籤都會寫回試算表，其他載具約數秒內跟著更新。

## 你會得到什麼

- 在試算表輸入**班級、座號、姓名**，網頁就排出座位表
- 平板用手指**拖放換位**（佔用座位會對調；拖到底下「尚未入座」可暫時移出）
- **隨機抽籤**（可設不重複，抽完再重設）
- 點學生：**+1 / +2 / +5**、**-1 / -2 / -5**
- **復原**上一步（加分、扣分、換位）
- **一鍵存檔**，並每 4 秒向雲端對時

## 試算表怎麼填

第一次打開「擴充功能 → Apps Script」並執行任何函式後，會自動建立三張工作表。

### 學生（你只要維護這張）

| 班級 | 座號 | 姓名 | 列 | 欄 | 分數 |
| --- | --- | --- | --- | --- | --- |
| 801 | 1 | 王小明 | 1 | 1 | 0 |
| 801 | 2 | 李美玲 | 1 | 2 | 0 |
| 802 | 1 | 陳志偉 |  |  | 0 |

- 一個試算表可放很多班，用「班級」欄區分
- **列／欄**可留空：第一次開網頁會依座號由左而右、由前到後自動入座
- **分數**請讓網頁改，不要和上課時同時手改，以免覆蓋

### 設定（選填）

| 鍵 | 值 | 說明 |
| --- | --- | --- |
| 網頁密碼 | （空白＝不用） | 平板網址若設成「任何人」，可加密碼防誤改 |
| 預設列數 | 6 | 新班級的前後排數 |
| 預設欄數 | 7 | 新班級的左右座位數 |
| 過道在第幾欄後 | 3 | 中間走道視覺空隙（例如 3 表示左 3 右其餘） |

`操作紀錄` 不用手填，給復原用。

## 安裝（約 5 分鐘）

1. 開一份新的 [Google 試算表](https://sheets.google.com)
2. **擴充功能 → Apps Script**
3. 刪掉預設的 `Code.gs` 內容，改貼本資料夾的 `Code.gs`
4. 按 **＋** 新增檔案，檔名必須剛好是：
   - `Index`（貼 `Index.html`）
   - `Styles`（貼 `Styles.html`）
   - `Client`（貼 `Client.html`）
5. 專案設定可把時區設成 `Asia/Taipei`（或貼上 `appsscript.json`）
6. 儲存後：試算表重新整理，應出現選單 **座位表**
7. 在 Apps Script：**部署 → 新增部署作業 → 網頁應用程式**
   - 說明：課堂座位表
   - 執行身分：**我**
   - 存取權限：**任何人**（學校平板通常沒登入你的 Google 帳號）
8. 複製網址，用平板 Safari / Chrome 開啟  
   iPad：分享 → **加入主畫面**，之後像 App 一樣全螢幕用

之後改過程式：部署 → **管理部署作業 → 編輯 → 新版本**，網址才會更新。

## 上課怎麼用

1. 先在「學生」工作表貼上該班名單
2. 平板打開網址，選班級
3. 拖學生排座位；點人加減分；抽籤點「隨機抽籤」
4. 下課前按 **一鍵存檔**（拖位其實會自動寫入，這顆按鈕是再保險一次）

其他電腦或平板開**同一個網址**就會讀到同一份座位與分數。若剛改完，等約 4 秒或把頁面拉下來重開即可。

## 注意

- 請用**老師的 Google 帳號**部署，資料在你的雲端硬碟
- 「任何人」代表知道網址的人都能改座位與分數；要防學生亂改，請在「設定」填 **網頁密碼**
- 同時兩台平板猛拖同一人，後寫入的會蓋過先寫入的；建議上課以一台主控平板為準
- 本資料夾是原始碼，**不會**在理化講義 GitHub Pages 上直接跑；要放到 Google 試算表裡才會動
