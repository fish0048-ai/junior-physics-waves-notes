# 兩層觀念補充（必做）

講義課文後面**一定要**再寫兩層補充，不能只抄課本。對齊 `sections/4-1.html` 的 `.extra` 與 `.gifted`。

| 層次 | class | 標籤 | 給誰看 | 寫什麼 |
|---|---|---|---|---|
| 國中程度 | `.extra` | `tag-purple`「觀念補充」 | 全班、段考 | 口訣、生活例子、易混概念、會考陷阱。用課文詞彙。 |
| 國中資優 | `.gifted` | `tag-gifted`「資優補充」 | 想再挖深的學生 | 同一觀念再往下問「為什麼／極端情況／定量關係／跨節連結」。仍用八年級讀得懂的句子。 |

標題慣例：國中程度用「國中必記：……」；資優用「資優補充」後接主題（不要再寫「國中必記」）。

## 放哪裡

每個**重點卡**（`#p1`、`#p2`…）課文之後、辨正／牛刀小試之前，兩層都要有。實驗卡若引入新觀念，同樣兩層。計算／延伸卡有新觀念就放；純套公式可只放國中程度。

卡片內順序：

1. 課文（def、表、圖）
2. `.tips`（可選）
3. `.extra`（**必備**，國中程度）
4. `.wrong-note`（可選）
5. `.gifted`（**必備**，國中資優）
6. 辨正 → 牛刀小試 → `inquiry-bridge`

一張重點卡可以有多則 `.extra`，但至少一則 `.gifted` 接在該卡補充區後面。

```html
<section class="extra">
  <div class="ex-title"><span class="tag tag-purple">觀念補充</span> 國中必記：標題</div>
  <ul class="q">
    <li>段考要分得清的那句。</li>
    <li>一個生活例子或口訣。</li>
  </ul>
</section>
<section class="gifted">
  <div class="ex-title"><span class="tag tag-gifted">資優補充</span> 標題</div>
  <ul class="q">
    <li>比課文深一層的「為什麼」，仍用國中話講完。</li>
  </ul>
</section>
```

## 兩層怎麼分（不要寫成同一段複製）

- **國中程度**：課文已經出現的觀念，換例子、口訣、對錯講清楚。學生讀完要能做牛刀小試。
- **國中資優**：課文沒寫、但八年級聽得懂的延伸。例如：為什麼管細比較靈敏（截面積）、熱容量＝質量×比熱、冰的結構讓密度變小、輻射隨溫度升高而變強（不寫史特凡定律公式）。可點出高中以後會再學的名字，但必須先用國中話解釋完。

## 禁止

- 只做其中一層。
- 兩層講同一句話。
- 資優層寫微積分、熵、大學熱力學、沒解釋的高中公式。
- 為了版型硬造空的 `.gifted`（沒有更深的內容就換一個真的能挖的角度）。
- 刪課文改成補充；補充是**外加**。
