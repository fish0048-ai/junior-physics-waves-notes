# 探究教學（詳細）

國中自然探究：讓學生對生活現象提出問題、先寫預測、用本節教材當證據、再形成主張。講義不是把課文改成問句，而是**在不刪原文的前提下，把課文變成證據鏈**。

## 一章一條鏈

先想整章要連續追問什麼。第 3、4 章現成例子：

| 節 | 探究問題 | 主張方向 |
|---|---|---|
| 3-1 | 波傳走了什麼？物質還是能量？ | 只傳能量，質點在平衡位置附近振動 |
| 3-2 | 聲音一定要有東西幫忙傳嗎？ | 力學波、縱波；真空不能傳聲 |
| 3-3 | 聲音碰到牆壁會消失嗎？ | 會反射；測距走來回要÷2 |
| 3-4 | 同一首歌樂器不同為什麼不一樣？ | 音調頻率、響度振幅、音色波形 |
| 4-1 | 光是彎著走還是直直走？ | 均勻介質直線前進；針孔倒立實像 |
| 4-2 | 鏡子裡的人是真的在鏡子後面嗎？ | 虛像；入射角＝反射角 |
| 4-3 | 泳池為什麼看起來比較淺？ | 折射因速率改變；透鏡成像 |
| 4-4 | 顯微鏡、相機、眼睛同一套邏輯？ | 實像接到平面 vs 再放大給眼看 |
| 4-5 | 白光裡真的藏著彩虹嗎？ | 色散；顏色＝反射或透過的光 |

新章也要先填這種表，再寫 HTML。問題必須：

1. 學生沒讀課文也能猜
2. 本節教材足夠回答
3. 下一節的問題能接在本節主張後面

## 章首怎麼寫

Hero 一段話用 `→` 串站名。Inquiry 卡**一段故事**，每站問題用 `<strong>`，不要再用 `.inquiry-map` 複製四張連結（小節卡由 `layout.js` 產生）。

對照：`index.html`、`ch4.html`。

`config.sections[].ask` 必須與該節 hero／探究標題同一句，差幾個字可以，意思不能換。

## 一節怎麼走（上課順序）

1. 看 hero 探究問題，寫「我的預測」（自動空位）
2. 看 `#inquiry` 的證據路線，點進重點
3. 每個重點先看「探究線索」、寫「這一站我先寫」，再讀定義與圖
4. 讀完看青色 `inquiry-bridge`：這一站證明什麼、下一問是什麼
5. `#memo` 當證據卡
6. `#claim` 用自己的話寫主張；「顯示答案」才出參考主張
7. `#drill` 檢驗主張，不要考本節沒教的東西

## `#inquiry` 必備三塊

**lead**：兩句現象 + 「先預測：……？」+ 「下面各站找證據」。

**path**：每個重點一列，`href` 對到 `#p1` 等。`<strong>` 用該重點標題，`<span>` 用該站線索問句。有實驗就加一列連 `#exp`。

**follow**：固定這句，只改若需要：

```html
<p class="inquiry-follow">對照<a href="#memo">考前速記</a>後，在<a href="#claim">本節主張</a>用自己的話回答，再用<a href="#drill">練習</a>檢驗。</p>
```

副標可寫「重點概覽：A　｜　B」，不要另做 `.overview`。

## 重點卡

`section-head` 正下方立刻放：

```html
<p class="inquiry-ask"><strong>探究線索：</strong>……？</p>
```

線索要能用本段圖或挖空回答，避免空泛「請認真看」。

課文（def、table、SVG）全部保留。課文後**必備兩層補充**：`.extra` 國中程度、`.gifted` 國中資優（見 [extras.md](extras.md)）。`tips`、易錯可選。最後、`</article>` 前：

```html
<p class="inquiry-bridge"><strong>這一站的證據：</strong>（本段結論）。下一站要問：（下一張卡的問題）。</p>
```

最後一個重點的 bridge 改成「收成速記後，就能回答本節問題。」

**危險：** 用搜尋取代 `</article>` 時，不要吃掉下一張卡的 `<article class="card" id="…">`。改完用搜尋檢查每個 `id="p2"` 是否仍包在自己的 article 裡。

延伸、計算卡可不加 ask／bridge。實驗卡建議加 ask（先預測再動手）。

## memo／claim／drill

memo 在表格前：

```html
<p class="inquiry-ask"><strong>證據卡：</strong>這些句子用來支撐下面的「本節主張」。先對照……，再決定你同不同意。</p>
```

claim：第一個不是 `.inquiry-next` 的 `<p>` 是參考主張（完整、可當顯示答案）。後面：

```html
<p class="inquiry-next">下一站要問：<a href="N-2.html">下一節問題？</a>　先用下面練習檢驗你的主張。</p>
```

最後一節改連下一章章首或上一章。

drill 在 `.drill-grid` 前：

```html
<p class="inquiry-ask"><strong>檢驗主張：</strong>做題時對照本節問題——……？</p>
```

基本題對應主張關鍵詞；進階題可計算或易錯，仍不超綱。

## 自動填答（`js/app.js`）

只在 `data-page="section"` 執行。

| 位置 | 標籤 | 儲存 key |
|---|---|---|
| `.inquiry-lead` 後 | 我的預測 | `predict` |
| `.inquiry-ask` 後（不含證據卡／檢驗主張） | 這一站我先寫 | `ask-0`… |
| `.inquiry-claim` 參考主張前 | 我的主張 | `claim` |

localStorage `jpwn.inquiryWrites`，鍵 `${classId}::${sectionId}`。換班事件 `jpwn-class-will-change` 先存、`jpwn-class-change` 再載。

**不要**在 HTML 手寫 `.inquiry-write`／textarea，否則會重複。

## 探究文案語氣

用學生聽得懂的話：小船、音叉、泳池、鏡子、紅蘋果。避免「本節學習目標為……」。預測要給對立選項（帶走／只晃、實像／虛像），學生才寫得出來。
