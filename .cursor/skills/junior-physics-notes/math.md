# 公式與圖表（正式數學格式）

講義、實驗專區、段考題裡，**公式與座標圖**一律用正式數學格式。光線示意、器材照片、原子模型不是圖表，維持 SVG／照片。

KaTeX 由 `js/layout.js` 自動載入。段考注入題目後要再呼叫 `JPWNMath.render()`（`exam.js` 已做）。

## 公式

- 獨立公式放 `.formula`，內容用 display 數學：`\[ ... \]`
- 句子中的符號用 inline：`\(D=\dfrac{M}{V}\)`
- 變數斜體（KaTeX 預設）、單位直立體：`\(\mathrm{g}\)`、`\(\mathrm{cm}^3\)`、`\(^{\circ}\mathrm{C}\)`、`\(\mathrm{m/s}\)`
- 分數用 `\dfrac`（獨立）或 `\tfrac`（行內）；乘號用 `\,` 或 `\times`，不要 `*`、`x`、`／`
- 等號用 `=`，減號用 `-`（LaTeX），不要 `＝`、`÷`
- 挖空不要放進 `\( \)` 裡，否則 KaTeX 會吃掉 input

```html
<p class="formula">\[\text{密度}=\dfrac{\text{質量}}{\text{體積}}\qquad D=\dfrac{M}{V}\]</p>
<p>同一物質 \(M\) 與 \(V\) 成正比，斜率就是密度 \(D\)。</p>
```

禁止：`D ＝ M／V`、`H = M x ΔT`、`1/2 * v * t` 當公式框。

## 座標圖（尤其要正式）

關係圖、加熱曲線、質量－體積圖用 `svg.diagram.math-graph`，**不要**兩條光軸加手寫字母。

必有：

1. 原點標 **O**
2. 軸箭頭（`<marker>` id 本頁唯一）
3. 軸名：變數斜體、單位括號直立體，例如 `M (g)`、`V (cm³)`、`T (°C)`、`t (min)`、`ΔT (°C)`
4. 刻度與數字（實驗數據圖還要畫出資料點）
5. 淡格線；圖例；`.caption` 用一句人話＋必要時 inline 數學
6. 白底，不要彩色卡片底冒充座標紙
7. **座標要算準**：資料點、直線、刻度用同一套比例（\(x=x_0+k_x X\)、\(y=y_0-k_y Y\)）。線必須穿過對應的點。4°C 必須在橫軸 \(T=4\) 的位置，不能畫在中間。加熱曲線水平段長度要跟熱量成正比（熔化 80 cal/g、水升溫 100 cal/g、沸騰 540 cal/g）。反比用雙曲線 \(D=M/V\)，不要隨手貝茲曲線。

範本見 `sections/1-2.html` 質量－體積圖、`sections/5-3.html` 加熱曲線。

示意圖（針孔、透鏡光路、凹液面、三態循環）維持普通 `.diagram`，但標的物理量仍用斜體符號。

## 數據表

表頭寫符號與單位：`\(V\,(\mathrm{cm}^3)\)`、`\(M\,(\mathrm{g})\)`、時間（分）。數字對齊，不要在儲存格裡寫 `10cm3`。
