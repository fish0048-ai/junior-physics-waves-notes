# 公式與圖表（正式數學格式・學術級精準）

講義、實驗專區、段考題裡，**公式與座標圖**一律用正式數學格式，必須在瀏覽器呈現為 KaTeX 學術排版（分數線、上標、希臘字母、直立單位）。光線示意、器材照片、原子模型不是圖表，維持 SVG／照片。

KaTeX 由 `js/layout.js` 自動載入（`JPWNMath`）。段考注入題目後要再呼叫 `JPWNMath.render()`（`exam.js` 已做）。題庫破公式可先 `JPWNMath.polish(text)` 再注入。

## 公式（不可破）

HTML **原始碼**寫 LaTeX（`.formula` 內用 `\[...\]`，行內用 `\(...\)`），但瀏覽器畫面必須是 **KaTeX 排版結果**（分數有橫線、變數斜體、希臘字母），**絕對不能**讓學生看到 `\[v=\dfrac{s}{t}\]` 這種原始碼字串。

若頁面出現原始碼，代表 `JPWNMath.render()` 沒跑成功；`.formula` 會由 `katex.render` 直接排版（會保存 `data-math-src`，同一格若誤放多條 `\[...\]` 也能拆開渲染，但 HTML 仍應一格一式）。
- **一行一式**：同一個 `.formula` 不要用 `<br>` 串兩條 `\[...\]`；請拆成兩個 `.formula`
- 變數斜體（KaTeX 預設）、單位直立體：`\(\mathrm{g}\)`、`\(\mathrm{cm}^3\)`、`\(^{\circ}\mathrm{C}\)`、`\(\mathrm{m/s}\)`、`\(\mathrm{g}/\mathrm{cm}^3\)`
- 分數用 `\dfrac`（獨立）或行內 `\dfrac`／`\tfrac`；乘號用 `\,` 或 `\times`，不要 `*`、`x`、`／`
- 等號用 `=`，減號用 `-`；指數用 `^{}`（`\(10^{-9}\,\mathrm{m}\)`）
- 挖空不要放進 `\( \)` 裡，否則 KaTeX 會吃掉 input
- 不要用 `<em>V</em>＝…` 冒充公式；改 `\(...\)`

```html
<p class="formula">\[\text{密度}=\dfrac{\text{質量}}{\text{體積}}\qquad D=\dfrac{M}{V}\]</p>
<p class="formula">\[\text{測量值}=\text{數值}+\text{單位}\]</p>
<p>同一物質 \(M\) 與 \(V\) 成正比，斜率就是密度 \(D\)。</p>
```

### 禁止（這些都不算「正確學術顯示」）

| 錯誤寫法 | 正確寫法 |
|---|---|
| `D ＝ M／V`、`密度=質量/體積` 當公式框 | `.formula` + `\[D=\dfrac{M}{V}\]` |
| `g/cm 3`、`cm 3`、`cm3` | `\(\mathrm{g}/\mathrm{cm}^3\)`、`\(\mathrm{cm}^3\)` |
| `10－9m`、`10-9 m` | `\(10^{-9}\,\mathrm{m}\)` |
| `H = M x ΔT`、`1/2 * v * t` | `\[H=M\,\Delta T\]`、`\[h=\dfrac{1}{2}vt\]` |
| `v＝fλ`、`9／5` 純文字當式子 | `\(v=f\lambda\)`、`\(\dfrac{9}{5}\)` |
| 全形 `＝／×÷` 充公式 | ASCII/`\times`/`\div` 包進 KaTeX |

化學式可用 HTML `<sub>`（H<sub>2</sub>O）或 `\mathrm{H_2O}`，同一頁一致即可。

## 座標圖（尤其要正式）

關係圖、加熱曲線、質量－體積圖用 `svg.diagram.math-graph`，**不要**兩條光軸加手寫字母。

必有：

1. 原點標 **O**
2. 軸箭頭（`<marker>` id 本頁唯一）
3. 軸名：變數斜體、單位括號直立體，例如 `M (g)`、`V (cm³)`、`T (°C)`、`t (min)`、`ΔT (°C)`
4. 刻度與數字（實驗數據圖還要畫出資料點）
5. 淡格線；圖例；`.caption` 用一句人話＋必要時 inline 數學
6. 白底，不要彩色卡片底冒充座標紙
7. **座標要算準**：資料點、直線、刻度用同一套比例（\(x=x_0+k_x X\)、\(y=y_0-k_y Y\)）。線必須穿過對應的點。4°C 必須在橫軸 \(T=4\) 的位置，不能畫在中間。加熱曲線水平段長度要跟熱量成正比（熔化 80 cal/g、水升溫 100 cal/g、沸騰 540 cal/g）。反比用雙曲線 \(D=M/V\)，不要隨手貝茲曲線。

範本見 `sections/1-2.html` 質量－體積圖、`sections/5-3.html` 加熱曲線。

示意圖（針孔、透鏡光路、凹液面、三態循環）維持普通 `.diagram`，但標的物理量仍用斜體符號。

## 數據表

表頭寫符號與單位：`\(V\,(\mathrm{cm}^3)\)`、`\(M\,(\mathrm{g})\)`、時間（分）。數字對齊，不要在儲存格裡寫 `10cm3`。
