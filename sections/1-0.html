重點 1　實驗室安全守則

實驗前、實驗時、實驗後

探究線索：一進實驗室，為什麼要先開窗？剩餘藥品可以直接倒進水槽沖掉嗎？

實驗室有藥品與火源，必須遵守安全守則。穿實驗衣或長袖、戴手套與護目鏡；聽完老師說明，得到許可後才領器材與藥品。

階段 安全守則
實驗前 1. 穿實驗衣或長袖衣服，戴手套、護目鏡。
2. 進入後先 保持 。
3. 確認逃生路線，以及滅火器、沖眼器的位置與用法。
4. 聽老師說明，得到指示後才領取器材與藥品。
實驗時 1. 依正確步驟操作器材。
2. 嚴禁 、追逐及嬉戲。
3. 不可用口嘗試任何藥品。

實驗後 1. 清洗器材並放回原位。
2. 廢棄物與剩餘藥品不可帶出，應 。
3. 擦淨桌面、椅子歸位，關窗關燈。
觀念補充 國中必記：先沖水，再報告
  • 藥品濺到皮膚或眼睛，第一步是大量清水沖洗，同時喊老師。先跑去健康中心，藥品還黏在皮膚上，傷害會繼續。
  • 剩餘藥品不要倒進水槽。有的會腐蝕水管，有的互相反應，有的污染水源。交給老師分類處理。
  • 實驗室禁止飲食，是因為手上、桌上可能沾到藥品，吃進去就中毒。
資優補充 為什麼一進門要開窗？
  • 很多藥品有揮發性蒸氣。窗戶一開，室內空氣被換成戶外空氣，蒸氣濃度比較不容易累積到會暈、會燃的程度。
  • 揮發性或有毒操作還要進通風櫥：櫥子把蒸氣抽走，不會吹到人臉上。普通開窗代替不了通風櫥。
  • 濃硫酸吸水性極強，濺到皮膚會邊放熱邊「搶水」。立刻大量沖水，是把酸稀釋並帶走熱，不是「等它自己乾」。

重點 2　認識實驗器材及操作

酒精燈、加熱、量筒與稀釋

探究線索：酒精燈可以用另一盞正在燒的燈去點嗎？量筒可以拿來配溶液、直接加熱嗎？

常見實驗器材

  • 刮勺、研缽及杵、燃燒匙、試管夾
  • 蒸發皿、三腳架及陶瓷纖維網、錶玻璃
  • 滴管、鐵架（含鐵夾、鐵環）
  • 漏斗、薊頭漏斗、試管
  • 吸濾瓶、錐形瓶、廣口瓶、燒杯

先認形狀：燒杯口大、錐形瓶口小底大、量筒細長有刻度；吸濾瓶多了側管，不要和錐形瓶搞混。三腳架見酒精燈那張。照片：Wikimedia Commons（CC BY-SA）

酒精燈使用注意事項

  1. 酒精量必須介於 。不足時用漏斗添加。酒精太少，內部蒸氣容易爆炸；太多容易溢出。
  2. 用 點燃，不可用燃燒中的酒精燈去點另一盞。
  3. 熄滅時用 ，不可用口吹熄。
  4. 若打翻起火，盡速用 滅火。

其他加熱設備：電子點火式本生燈以瓦斯為燃料，溫度可達 1000°C 以上。加熱板可均勻加熱並提供穩定溫度，不可用於大量易揮發或可燃物。

容器的使用與液體操作

  • 除了 外，其餘容器不可直接加熱，須放在 上或隔水加熱。
  • 試管加熱：試管夾夾近管口，管口稍傾斜以增加受熱面積，且不可將試管口朝向人體。
  • 量筒只用量體積，不可在其中配製溶液或進行反應，也不可加熱。
  • 藥品應倒入小燒杯或試管再以滴管吸取，不可把滴管直接伸進藥品瓶。
  • 傾倒液體應使液體沿 流下；混合時用玻璃棒攪拌，試管可塞橡皮塞搖晃。

量筒讀數與濃酸稀釋

測量 ：視線對齊水面中央 （凹面）。

測量 ：視線對齊液面中央 （凸面）。

稀釋濃酸或強鹼：將濃酸或強鹼沿玻璃棒緩緩 ，並不斷攪拌。稀釋會放出熱量；若把水加入酸中，局部過熱會使酸液飛濺。

觀察藥品：不可把眼、口、鼻靠近容器口。嗅聞氣味用 。有毒或揮發性藥品應在 內進行。

觀念補充 國中必記：量筒只量、不配、不燒
  • 量筒刻度細、壁薄，受熱或攪拌容易裂，也量不準。要配溶液用燒杯；要加熱用燒杯加陶瓷纖維網，或用試管。
  • 陶瓷纖維網讓火焰熱量散開，容器受熱比較均勻，比較不容易局部過熱而裂。
  • 口訣：酸入水，沿棒走。反過來會噴。
資優補充 為什麼酒精太少反而危險？
  • 燈壺上方是酒精蒸氣。蒸氣在空氣中濃度落在「可燃範圍」時，一點火會在壺內爆燃。酒精裝到 1/2～2/3，液面較高，蒸氣空間較小，比較不容易積到危險濃度。
  • 用一盞燈去點另一盞，酒精可能從燈口濺出，兩邊一起燒。所以規定用火柴或打火機。
  • 水的凹液面、水銀的凸液面，來自液體分子間作用力與玻璃壁的差異。國中只要記讀數位置：水看谷、水銀看峰，視線與該點齊平，才不會有視差。

重點 3　控制變因法

操縱、控制、應變

探究線索：想知道「加熱時間會不會讓水溫升更高」，實驗組和對照組可以同時改時間又改水量嗎？為什麼？

要了解某一因素對事件的影響，採用的實驗方法叫做 。

  1. ：會影響某一事件的因素。
  2. ：實驗組和對照組「不一樣」的那個因素。通常只限 ，才能確定是它造成差異。
  3. ：實驗組和對照組「保持相同」的因素，可以有很多個。
  4. ：操縱變因對事件造成的影響，也就是實驗結果。
觀念補充 國中必記：只改一件，其餘都要一樣
  • 口訣：操縱＝故意不一樣（通常一個）；控制＝故意一樣（可以很多）；應變＝結果怎麼變。
  • 例如比較「水量會不會影響升溫」：操縱變因是水量；酒精燈、加熱時間、杯子種類是控制變因；溫度變化是應變變因。
  • 「變因」三個字本身＝所有可能有影響的因素，不只是組間不同的那一個。
資優補充 一次改兩件會怎樣？
  • 若同時改水量又改加熱時間，最後溫度不同，你分不清是水多、還是燒得久。兩個操縱變因纏在一起，叫做變因混淆，結論就站不住。
  • 對照組不是「什麼都不做」，而是「除了要檢驗的那一件，其他都跟實驗組相同」。這樣才能說：差異來自那一件。
  • 科學史上，控制變因讓實驗從「感覺好像有關」變成「可以重複驗證」。後面量密度、比熱，都是同一套邏輯。

安全、器材、變因三句話

證據卡：這些句子用來支撐下面的「本節主張」。先對照守則與操作，再決定你同不同意。

  • 進實驗室先開窗通風；濺到藥品先大量清水（或沖眼器）；剩餘藥品分類集中，不倒水槽。
  • 酒精燈裝 1/2～2/3，火柴點、燈罩蓋、打翻用濕抹布。量筒只量不配不燒。水讀凹面最低處，水銀讀凸面最高處。濃酸沿玻璃棒加入水中。
  • 控制變因法：操縱變因通常一個，控制變因可很多，應變變因是結果。
主

本節主張

先安全、會操作，實驗才公平

進實驗室要先想安全：開窗通風、聽老師、禁止飲食；藥品碰到皮膚先大量沖水再報告，剩餘藥品分類集中處理。每種器材有固定用法，酒精燈、量筒和稀釋濃酸都不能隨便做。要知道某一因素的影響，一次只改一個操縱變因，其餘保持相同，再看應變變因。
