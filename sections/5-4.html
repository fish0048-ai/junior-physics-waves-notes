重點 1　傳導

靠接觸把熱帶走，固體最有效

探究線索：熱可以靠傳導、對流、輻射傳播。哪兩種一定要有介質？冬天摸鐵椅為什麼比木椅冰？

熱的傳播有 、 、 。 傳導和對流需要 ， 輻射不需要。

觀念補充 國中必記：三種傳熱怎麼分？
  • 傳導：靠接觸，物質本身不太搬家。固體最有效。
  • 對流：靠液體或氣體流動，熱跟著物質一起搬家。一定要有流體。
  • 輻射：不需要介質，以熱射線的方式傳遞。太陽熱傳到地球就是這一條。
  • 生活裡常常三種同時發生：握熱湯匙是傳導，火爐上方是對流，臉被太陽曬熱是輻射。題目問「主要」靠哪一種，選最明顯的那條路。

傳導：物體 時傳遞熱。固體的主要傳熱方式是傳導；流體也能傳導，但粒子較疏，效率較差。

金屬容易導熱，稱為 ； 非金屬不易導熱，稱為 。

  • 鍋身用金屬、握把用塑膠或木頭。
  • 厚肉烤肉插金屬針，熱比較快傳到內部。
  • 蓬鬆棉被、雙層玻璃杯：中間的空氣幾乎不流動，是不良導體，所以保溫。
觀念補充 國中必記：靜止空氣為什麼能保溫？
  • 固體、液體、氣體都能傳導，只是固體粒子靠得近，傳導最快；流體粒子較疏，傳導很差。液體、氣體的主要傳熱方式是對流，不是傳導。
  • 空氣若幾乎不流動，對流啟動不了，傳導又差，所以蓬鬆棉被、保麗龍、雙層玻璃中間的空氣層都能隔熱。一旦空氣流動起來，熱就會被對流帶走。
  • 導熱快慢看的是良導體／不良導體，不是比熱。比熱大的物質升溫慢，但不代表它一定不導熱。
  • 冬天摸鐵椅比木椅冰：兩椅溫度差不多，鐵是良導體，把手上的熱帶走得快，感覺才更冷。
資優補充 傳導其實是粒子在「撞來撞去」
  • 熱端的粒子振動比較劇烈，碰到隔壁粒子就把振動傳下去。金屬容易傳導，和裡面比較能自由移動的電子有關（國中記「金屬通常是良導體」即可，高中會再講自由電子）。
  • 真空幾乎沒有粒子可撞，所以傳導、對流都停擺；但輻射是電磁波，真空擋不住。這就是保溫瓶為什麼還要鏡面。
  • 雙層玻璃中間若是空氣，仍有一點傳導；抽成真空後這條路幾乎斷掉，所以「乙（真空）」比熱「丙（空氣）」更隔熱。

重點 2　對流

流體流動把熱帶走

探究線索：燒杯底部加熱，熱水往上還往下？白天海邊的風從海吹向陸地，還是相反？

對流：藉由 的流動傳遞熱，主要發生在流體。底部受熱膨脹， 變小而上升，上方較冷、密度較大的流體下沉，形成循環。

海風與陸風

  • 白天：陸地比熱小、升溫快，熱空氣上升，風從 吹向陸地（海風）。
  • 夜晚：陸地降溫快，海面較暖，風從陸地吹向 （陸風）。
  • 冷氣機裝 （冷空氣下沉）；暖氣裝 （熱空氣上升）。
  • 煙囪愈高，對流愈好，煙愈容易排走。
  • 手在火爐上方主要感到對流；在旁邊主要感到輻射。
  • 冬天湖面結冰：水冷到 4°C 會下沉，全湖接近 4°C 後，更冷的水留在表面結冰，底下仍約 4°C，生物能活。
觀念補充 國中必記：海風、陸風先問誰比較熱
  • 口訣：熱的那邊空氣上升，風從涼的那邊吹過來補。白天陸地比熱小、比較熱 → 海風（海→陸）。夜晚陸地比較涼、海面比較暖 → 陸風（陸→海）。
  • 冷氣裝高、暖氣裝低，也是同一套：冷空氣下沉、熱空氣上升，讓整間房間形成對流循環。
  • 試管加熱：加熱底部才能整管對流、比較快沸騰；只加熱中段或上方，上面的熱水升不了、下面的冷水也對流不到，主要只靠緩慢的傳導。
  • 手在火爐正上方：熱空氣上升，主要是對流。手在旁邊：空氣不太流過來，主要是輻射。
資優補充 對流圈：上升的對面一定要有下沉
  • 流體受熱膨脹、密度變小才上升；旁邊較冷、密度較大的就會補下來，形成一圈。沒有「只上升、不下沉」的對流。
  • 海陸風本質是兩個對流圈：白天陸地熱柱上升、海面下沉補償；夜晚對調。陸海比熱不同，只是在決定「白天誰比較熱」。
  • 水在 4°C 密度最大，所以湖水不會「愈冷愈往下沉到湖底結冰」。冷過 4°C 的水變輕，留在表面，冰才從上往下長，底下生物才有 4°C 的水可以待。
辨正思考

1. ( ) 白天吹海風，是因為陸地升溫比海水快。

2. ( ) 冬天湖泊從表面開始結冰。

3. ( ) 冷氣機應裝在房間下方。
訂正：

3. 試管甲加熱中段、乙加熱底部，較快整管沸騰的是 （對流能把熱送到上面）。

重點 3　輻射與保溫

不需介質；顏色決定吸熱快慢

探究線索：太陽熱怎麼穿過真空來到地球？同樣一杯熱水，黑杯和白杯誰涼得比較快？

輻射： 就能傳遞熱。任何物體都會輻射熱。

  • 表面顏色愈深，愈容易 或放出輻射熱；顏色愈淺愈不容易。
  • 冰箱黑色散熱片、淺色瓦斯桶、夏天淺色衣服、冬天深色衣服。
  • 太陽能熱水器的集熱板做成 以吸收輻射；水在管內循環則靠對流。
  • 烤箱：食物主要靠輻射，金屬架靠傳導。

保溫：擋住或減少三種傳熱

  • 塑膠瓶蓋：減少傳導，也擋住 。
  • 真空夾層：不能傳導、不能對流。
  • 光滑鏡面：減少 損失。
觀念補充 國中必記：深色易吸也易放；保溫瓶三招
  • 輻射不需要介質，所以太陽熱能穿過太空。任何溫度的物體都會輻射，不是「低於 0°C 就停止」。
  • 顏色口訣：深色容易吸收，也容易放出輻射熱；淺色不容易吸、也不容易放。所以黑杯熱水涼得快、黑散熱片容易散熱；夏天穿淺色、瓦斯桶漆淺色，是為了少吸熱。
  • 保溫瓶三招要對得起來：塑膠蓋 → 減少傳導、擋住對流；真空夾層 → 不能傳導、不能對流（輻射還在）；光滑鏡面 → 把輻射反射回去。真空擋不住輻射，所以一定還要鏡面。
資優補充 易吸的也易放，而且愈熱輻得愈兇
  • 黑色表面吸收本領強，放出本領也強：白天黑衣服吸熱快，晚上（或裝熱水時）散熱也快。白色則兩頭都慢。所以「黑杯熱水涼得快」和「黑衣夏天熱」不矛盾。
  • 任何溫度高於絕對零度的物體都在輻射；溫度愈高，通常輻射能量愈多。太陽極熱，才能隔著真空把熱送到地球。
  • 太陽能熱水器：集熱板黑色負責吸收輻射；水管裡的水變熱後密度變小往上走，冷水補下來，這段是對流。一塊板同時用到兩種傳熱。
辨正思考

1. ( ) 真空夾層可阻止傳導和對流。

2. ( ) 容易吸收輻射的物體，也容易放出輻射。

3. ( ) 溫度低於 0°C 的物體不會輻射。
