本節探究　冰塊、糖水、鐵生鏽，哪個還是「原來那個東西」？

重點概覽：三態　｜　物理與化學　｜　純物質與混合物　｜　分離

冰塊變成水，看起來變了；鐵釘生鏽，也變了。先預測：哪一種「變」之後還能變回去、本質沒換？哪一種已經變成別的東西？下面各站找證據。

重點 1　物質的三態

有質量、占空間；固、液、氣不一樣

探究線索：光、熱、電算物質嗎？把針筒口堵住，裡面裝水和裝空氣，活塞誰推得下去？

凡具有 、 者均為物質。例如水、空氣、木材、鐵。

能量不具有質量、不占有空間，例如光、熱、電，不是物質。

物體由物質組成。剪刀、迴紋針都是鐵做的，都會被磁鐵吸引；冰糖、方糖、砂糖都是蔗糖，都甜、都能溶於水。

狀態形狀體積
固態一定一定
液態隨容器改變一定
氣態充滿容器無一定（可充滿任何形狀的容器）

定壓時，造成物質三態變化的主因是 。

液體與氣體的可壓縮性

  • 液體：無法推動活塞 → 可壓縮性，體積固定。
  • 氣體：施力愈大，針筒內體積愈小 → 可壓縮性，體積隨容器改變。
觀念補充 國中必記：物質 vs 能量
  • 能放上秤、會占位子的才叫物質。空氣看不見，但輪胎打氣後變重、也占空間，所以空氣是物質。
  • 光、熱、電、聲音是能量，不是物質。段考常把「光」混進物質例子裡。
資優補充 為什麼液體幾乎壓不下去？
  • 液體粒子已經靠得很近，中間幾乎沒空隙可再擠；氣體粒子離得遠、空隙多，所以一壓體積就明顯變小。
  • 固體也幾乎不可壓縮。課文對照的是「液 vs 氣」：只有氣體在國中實驗裡明顯看得到體積被壓小。
辨正思考

1. ( ) 凡具有質量、占有空間者均為物質。

2. ( ) 定壓時，造成物質三態變化的主因是溫度改變。

3. ( ) 液體的可壓縮性比氣體大。
訂正：

4. ( ) 液體沒有固定形狀，但有一定體積。

牛刀小試

1. 常壓下，造成物質三態變化的主因是 。

2. 「固體和氣體都具可壓縮性」是 （只有氣體明顯可壓縮）。

3. 有一定體積、形狀隨容器改變的是 。

4. 不論箱子多大都能充滿整個箱子的是 。

甲冰糖　乙冰　丙酒精　丁氧氣　戊鐵塊　己水蒸氣　庚豆漿

5. 有一定體積和形狀： 。

6. 有一定體積、無一定形狀： 。

7. 無一定體積、可充滿容器： 。

延伸學習　壓力對物質狀態的影響

冰的熔點、水的沸點，跟氣壓有關

探究線索：細鐵絲加砝碼壓在冰塊上，鐵絲為什麼能穿過去、冰塊卻沒斷成兩半？高山上的水為什麼不到 100°C 就滾了？

1. 壓力對冰熔點的影響

對冰增加壓力，熔點會 （可在低於 0°C 時熔化）。

  • 細線＋重錘壓在冰塊上：線下方壓力大，冰熔化成水，線往下沉。
  • 線上方壓力恢復，水再 ，所以冰塊沒有斷成兩半。

2. 壓力對水沸點的影響

  • 壓力變小，水的沸點會 。 例：高山氣壓低，水未達 \(100\,^{\circ}\mathrm{C}\) 就沸騰，食物不易煮熟。
  • 壓力變大，水的沸點會 。 例：壓力鍋約 2 大氣壓，沸點可達 \(120\,^{\circ}\mathrm{C}\)；醫院高壓蒸汽鍋約 11 大氣壓，沸點約 \(186\,^{\circ}\mathrm{C}\)，可用來消毒。
觀念補充 國中必記：熔點降、沸點升
  • 對冰加壓：熔點下降（水的特例）。對水加壓：沸點上升（大多數液體都這樣）。
  • 段考：壓力變大 → 冰的熔點下降、水的沸點上升。
資優補充 為什麼冰越壓越容易熔？
  • 冰熔化成水時體積會變小（冰比較鬆）。加壓等於「幫忙它變成比較占空間小的狀態」，所以熔點往下掉。大多數物質相反：固態比較密，加壓會讓熔點升高。
牛刀小試

1. 壓力變大：冰的熔點 、 水的沸點 。

2. 高山煮麵，水很快沸騰卻不易煮熟，是因為氣壓 、 沸點 。

這一站的證據：加壓讓冰更好熔、讓水更難滾。下一站問：變化之後，還是不是原來那個物質？

重點 2　物質的變化與性質

有沒有產生新物質；能不能用觀察量出來

探究線索：蠟燭從固體變成液體、再變成氣體，最後燃燒發光——哪幾步還沒產生新物質？

物理變化化學變化
定義 只有狀態改變，本質沒變，不會產生新物質。 本質改變，會產生新物質。
舉例 水結冰、水變水蒸氣、葡萄糖溶於水、玻璃破碎、酒精受熱膨脹、冰淇淋熔化、剪紙 火柴燃燒、鐵生鏽、煮熟食物、光合作用、呼吸作用

蠟燭燃燒過程

同一支蠟燭可以同時發生物理變化和化學變化，不是「一次只能一種」。

物理性質化學性質
定義 用觀察、測量等不改變物質組成的方法察覺。 發生化學變化時表現出來的特性。
舉例 顏色、透明度、狀態、密度、質量、熔點 可燃性、助燃性、酸鹼性、腐蝕性、活性
觀念補充 國中必記：有沒有新物質
  • 物理變化：切、溶、熔、凍、蒸發、破碎——還是原來那一種。
  • 化學變化：燒、鏽、消化、光合作用——變成別的。
  • 「白色的手機」講的是顏色，屬於 。
資優補充 溶解為什麼多半算物理變化？
  • 糖溶在水裡，把水蒸發還能拿回糖，組成沒變。國中把「溶解」當物理變化。
  • 若溶的過程真的發生反應（例如金屬鋅加鹽酸冒氫氣），那就已經是化學變化，不能只叫溶解。
辨正思考

1. ( ) 當發生化學變化時，必會產生新物質。

2. ( ) 物質發生變化的過程中，物理變化或化學變化不會同時發生。
訂正：

3. ( ) 任何物質皆有物理或化學性質。

4. ( ) 一支「白色」的手機，此為描述手機的物理性質。

牛刀小試

1. 下列屬於物理變化： （汽油揮發、牛油熔化、打果汁、鉛筆寫字、衣服曬乾、撕紙、水銀脹縮、磨麵粉、樟腦丸昇華、打破玻璃杯）。

2. 溫度計酒精柱上升，是酒精的 。

3. 車輪因摩擦而爆胎，主要是 （氣體受熱膨脹），不是燃燒。

這一站的證據：有沒有新物質，決定物理還是化學。下一站：純水和鹽水，性質固定不固定？

重點 3　純物質與混合物

熔點、沸點固不固定

探究線索：1 大氣壓下，純水沸騰時溫度計會停在 \(100\,^{\circ}\mathrm{C}\)；加了鹽，液柱會停在同一格嗎？

  • 純物質：只由一種物質組成，熔點、沸點、密度等性質 。 例：金、氧氣、葡萄糖、氯化鈉。
  • 混合物：兩種以上純物質以任意比例混合；沒有固定熔點、沸點，性質隨比例改變，但各成分仍保有原來性質。例：空氣、鹽水、合金、酒、墨水。

水裡溶的鹽愈多，沸點愈 。

觀念補充 國中必記：沸點範圍＝混合物
  • 純物質：沸點是一個確定的溫度。混合物：常出現「\(150\sim 154\,^{\circ}\mathrm{C}\)」這種範圍。
  • 酒標 12% 酒精，是混合物；酒精本身（乙醇）才是純物質。
資優補充 鹽水為什麼比較難滾？
  • 水要變成蒸氣，水分子得跑出液面。鹽粒子佔了一些位子、也拉住周圍的水，水分子比較不容易逃，所以要更高溫度才沸騰。
辨正思考

1. ( ) 純物質有固定的熔點與沸點。

2. ( ) 混合物各成分會失去原來的性質。
訂正：

牛刀小試

1. 金、氧氣、葡萄糖、氯化鈉都是 。

2. 空氣、鹽水、合金、酒、墨水都是 。

3. 沸點範圍 \(150\sim 154\,^{\circ}\mathrm{C}\) 的液體是 。

這一站的證據：純物質性質固定；混合物可用性質差異分開。下一站動手：鹽和沙怎麼拆？

實驗 2-1　混合物的分離

溶解 → 過濾 → 結晶

完整步驟（摺濾紙、玻璃棒引流、漏斗頸貼壁）見實驗專區 2-1。這裡只留精要與讀圖。

探究線索：乾的鹽沙倒上濾紙，兩者都會過嗎？加水以後，誰溶、誰被擋住？

目的：利用粒子大小與溶解性的差異，分離食鹽和沙子。

實驗精要

  1. 鹽＋沙加入水中攪拌：鹽 ，沙不溶。
  2. 過濾：液體沿 倒下；棒端靠濾紙；漏斗頸下端 燒杯內壁，避免濺出。
  3. 濾液放蒸發皿加熱結晶；可加蓋倒置漏斗，減少鹽晶爆濺。

流程： → → 。

  • 乾的鹽沙：兩者顆粒都大於濾紙孔隙，都過不去。
  • 加水後：鹽溶成很小的粒子，隨水通過；沙留在濾紙上。
  • 蒸發：水的沸點遠低於鹽，水先跑掉，鹽留在蒸發皿。
觀念補充 國中必記：過濾靠粒子大小
  • 能過濾紙的是「夠小」的粒子（溶液），不是「溶質一定過得去」。乾的鹽過不去。
資優補充 漏斗頸為什麼要貼壁？
  • 液體沿壁流下去，比較不會濺、氣泡也比較少。玻璃棒則讓水流成一條，不沖破濾紙。

這一站的證據：溶解性＋粒子大小可以拆鹽和沙。下一站把方法做成四種選擇題：蒸餾、結晶、色層分析差在收什麼。

重點 4　分離物質的方法

溶解過濾、蒸餾、蒸發結晶、色層分析

探究線索：要把墨水裡的水拿出來，該蒸餾還是蒸發結晶？色筆的墨水點為什麼不能泡到水裡？

  • 溶解過濾法：靠 和 。 小粒子過孔隙，大顆留在濾紙上。
  • 蒸餾法：靠 不同，收集沸點較低的液體。例：從墨水蒸出純水。
  • 蒸發結晶法：也靠沸點不同，收集沸點較高的固體。例：鹽田曬鹽。
  • 濾紙色層分析法：靠濾紙 力和在溶劑中移動快慢不同，把顏色拆開。
觀念補充 國中必記：蒸餾收液體、結晶收固體
  • 都利用沸點差：想要水用蒸餾；想要鹽用蒸發結晶。
  • 色層分析：移動快的色素走得高。
資優補充 墨點若泡到水裡會怎樣？
  • 色素直接溶進水盤，不會再沿濾紙分層，實驗就失敗。所以水位必須低於起始點。
